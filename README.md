# Knight’s Contact Manager
Knight’s Contact Manager is a full-stack web application developed for COP4331 that allows users to create an account, log in, and manage a personal list of contacts.
The application demonstrates a complete LAMP-stack workflow, including frontend UI design, backend API development, and database integration.

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP (REST-style APIs)
- **Database:** MySQL
- **Server Hosting:** DigitalOcean (Ubuntu, Apache)
- **Design & Collaboration:** Figma, GitHub, Discord

## Core Features
- User registration and login
- Secure authentication via backend API
- Contact management interface (add, view, edit contacts)
- Frontend-backend communication using JSON and XMLHttpRequest
- Persistent data storage using MySQL

## How to Run the Application
1. Open the deployed site in a web browser.
2. Register a new user account using the Sign Up option.
3. Log in with your credentials.
4. Access and manage contacts through the contact manager interface.
